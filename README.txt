FIGHT FOR DSE - how to use

ADD A NOTE (2 steps)
1. In the "notes" folder, create a file, e.g. m1-calculus.md. Write in Markdown; equations use $...$ or $$...$$.
2. Add an entry to notes.json (copy the existing one, change slug to the file name without .md, plus title, subject, date, desc). Mind the commas.

PUT IT ONLINE (free, you control the code)
Option A - Cloudflare Pages or Netlify: create a free account, choose "upload / drag and drop", drop this whole folder.
Option B - GitHub Pages: create a repository, upload these files, turn on Pages in Settings.
Only people with your account (or repository access) can change the site, so only you can add notes.

ADSENSE
- The AdSense script is already inside <head> in index.html, and ads.txt is included. Keep ads.txt in the top folder.
- AdSense usually needs your own domain name and a privacy policy page before approving a site.
